## What's Changed

### New Features
- Added `md pdf-profile codex` for drafting replayable Markdown PDF profiles from bounded document signals, user intent, font hints, and optional base profiles. The helper supports deterministic fallbacks, dry-run previews, progress feedback, validated patch domains, and optional diagnostic reports.
- Added `md pdf-template codex` for generating validated `template.html`, `style.css`, and managed static cover assets from bounded layout, typography, and cover signals. Generated bundles preserve renderer ownership rules and can be reviewed before deterministic rendering.
- Added `md pdf-project codex` for coordinating profile and template generation in one project directory, including cross-phase validation, optional diagnostics, dry-run behavior, and a deterministic follow-up render command.
- Added `md to-pdf --bundle <directory>` as optional top-level discovery for profile, template, and stylesheet inputs. Partial bundles are supported, ambiguous roles fail without guessing, and direct `--profile`, `--template`, and `--css` options remain fully supported and authoritative for their roles.

### Reliability and Safety
- Hardened Markdown PDF Codex helper output planning, collision handling, report sequencing, path redaction, and failure behavior so unsafe or incomplete runs do not leave misleading project artifacts.
- Strengthened template asset handling for local cover images, CSS references, imports, and `srcset` values; rejected unsupported animated covers and constrained generated layout, font, and asset decisions to validated contracts.
- Bounded render-bundle report classification and file reads, preserved explicit profile precedence, and skipped unnecessary bundle profile reads when that role was already selected directly.

### Compatibility and Maintenance
- Raised the Node.js runtime requirement to `>=22.23.0` and aligned release workflows with Node.js `24.18.0` security releases.
- Updated the Codex SDK baseline to `0.144.1` and refreshed runtime and development dependencies, including DuckDB, Commander 15, PDF.js 6, Shiki, Oxc, and `tsdown`.
