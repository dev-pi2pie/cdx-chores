## What's Changed

### Maintenance
- Updated the reliable dependency maintenance set for the stable `v0.1.4` line, including `@openai/codex-sdk`, Shiki, `fast-xml-parser`, `yaml`, `yauzl`, Inquirer prompts, TypeScript types, Oxc tooling, and `tsdown`.
- Refreshed the Bun lockfile and preserved the existing package version-range conventions.
- Kept the existing `@xmldom/xmldom` override in place for the `mammoth` transitive dependency.
- Removed an unused root-level stack output fixture from the release range.

### Compatibility
- Codex SDK baseline for `v0.1.4`: `0.137.0`
- Deferred `@duckdb/node-api`, `commander@15`, and `pdfjs-dist@6` to separate compatibility-focused passes.
- This release contains dependency maintenance and release housekeeping only; it does not introduce new CLI commands or user-facing workflow changes.
