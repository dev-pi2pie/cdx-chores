## What's Changed

### DOCX Rename Suggestions

- Replaced Mammoth with a built-in DOCX reader for Codex-assisted rename suggestions. It reads document properties, headings, and text to help choose a title.
- DOCX reading now runs separately from the CLI, with [limits on file size, processing time, and memory](https://github.com/dev-pi2pie/cdx-chores/blob/v0.2.1/docs/references/docx-extraction.md#default-limits). Rename falls back to its usual rules if reading fails.
- Removed Mammoth and its `argparse` / `sprintf-js` dependency chain.

### XML Handling

- Added stricter checks for malformed XML. Invalid document properties can still be ignored when the document text is readable.
- Fixed DOCX reading failures caused by XML instructions such as `xml-stylesheet` or `xml-model` at the start of a file.

### Compatibility

- Codex SDK baseline for `v0.2.1`: `0.163.0`.
- Node.js requirement remains `>=22.23.0`.
