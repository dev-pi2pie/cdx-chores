## What's Changed

### Markdown PDF Page Numbers And Covers

- Added Profile-owned page numbering, headers, footers, and page chrome, with
  logical and physical numbering across cover, table-of-contents, and body
  pages.
- Added Formal guide and Interactive authoring for page-number settings and
  metadata covers, plus upfront Template and Project compatibility checks.
- Added migration guidance for older Profile revisions where `{pages}` meant the
  physical PDF total. Use `{pdfPages}` for that behavior; revision 3 uses
  `{pages}` for the final logical number.

### Codex Request Timeouts And Recovery

- Added duration-based `--codex-timeout` controls across Codex-assisted rename,
  data, Markdown PDF, and Interactive workflows, with analyzer-specific rename
  overrides.
- Deprecated the rename-only `--codex-images-timeout-ms` and
  `--codex-docs-timeout-ms` options. They remain supported and print migration
  guidance when used.
- Improved timeout summaries while preserving workflow-specific retry,
  fallback, and recovery behavior.

### Doctor And CLI Diagnostics

- Added compact, detailed, and JSON `doctor` views, including view selection in
  Interactive mode.
- Added stream-aware diagnostic emphasis while preserving plain output for
  redirection, structured data, `NO_COLOR`, and `--no-color`.

### Compatibility And Maintenance

- Codex SDK baseline for `v0.1.7`: `0.149.1`.
- Refreshed reviewed dependencies while retaining Node.js `>=22.23.0`.
