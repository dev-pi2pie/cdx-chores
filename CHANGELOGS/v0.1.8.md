## What's Changed

### Codex Execution Options

- Added `--codex-model`, `--codex-provider`, and `--codex-reasoning-effort`
  to supported rename, data, Markdown PDF, and explicit Interactive workflows.
- Model and provider inherit Codex configuration when omitted. Helper reasoning
  defaults to `low`.
- Explicit selections are retained across retries, repairs, and Interactive
  regeneration without rewriting Codex configuration.

### Codex Configuration And Catalog Discovery

- Added `codex-info`, `codex-info models`, and `codex-info providers` to inspect
  configuration and reported catalog metadata without drafting a helper result.
- Added compact, detailed, and JSON views with terminal-aware styling.
- Provider discovery lists configured definitions only. Built-ins are not
  enumerated.
- Model discovery lists the Codex catalog. Availability depends on the runtime
  configuration.

### PDF Document Extraction

- Fixed page and loading-task cleanup when extracting PDF evidence for document
  renaming, while preserving extracted evidence and original failure reasons.
- Fixed standard-font asset resolution for built ESM and CJS packages and
  upgraded PDF.js to `6.3.289`.

### Compatibility

- Codex SDK baseline for `v0.1.8`: `0.153.4`.
- Node.js requirement remains `>=22.23.0`.
