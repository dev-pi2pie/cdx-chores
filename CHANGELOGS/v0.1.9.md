## What's Changed

### Markdown PDF

- Interactive Codex Assistant now collects page-number and repeating
  header/footer choices for Profile and Project bundles. Review shows the
  resulting settings; optional reports omit entered page text.
- Improved Project cover handling: Profile-owned text covers render through the
  managed Template, selected images remain image covers, and negated requests
  do not enable a cover.
- Fixed cover rendering of literal `$` text, including currency, in built-in
  and managed Project covers.

### Compatibility

- Codex SDK baseline for `v0.1.9`: `0.156.1`.
- Node.js requirement remains `>=22.23.0`.
