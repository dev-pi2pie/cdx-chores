## Goal

Refresh the reviewed runtime and development dependency set for
`v0.1.8-canary.2`, synchronize the public Codex SDK baseline, and verify the
built Node.js package across its supported runtime boundary.

## Approved Package Set

- `@inquirer/prompts`: `8.6.0` -> `8.7.0`
- `@inquirer/search`: `4.3.0` -> `4.3.1`
- `@openai/codex-sdk`: `0.150.1` -> `0.151.0`
- `fast-xml-parser`: `5.11.0` -> `5.11.1`
- `@types/node`: `25.9.5` -> `26.4.0`
- unchanged: `mammoth` remains at the release-age-qualified `1.12.1`

## Supply-Chain Review

- Confirmed repository, maintainer, registry integrity, and signature
  continuity for every approved direct package before installation.
- Confirmed SLSA provenance attestations for the Codex SDK, Inquirer packages,
  and Fast XML Parser target releases.
- Compared the Codex SDK tarballs. The published JavaScript, source map,
  README, and license are unchanged; the declaration surface only adds the
  `persistent` reasoning-effort value, and package metadata advances the
  matching bundled Codex CLI to `0.151.0`.
- Compared the Inquirer tarballs. The prompts entry JavaScript is unchanged,
  while the release advances the coordinated prompt packages. Search has no
  JavaScript source change and exposes the updated flattened configuration
  type through its declarations.
- Compared the Fast XML Parser tarballs. Version `5.11.1` replaces the
  attribute validator's potentially quadratic regular expression with a
  forward-only scanner; its declared runtime dependency set is unchanged.
- Confirmed DefinitelyTyped publisher, repository, integrity, and signature
  continuity for `@types/node`. The type-only update advances `undici-types`
  from the `7.24.x` range to `8.3.0`.
- The pre-update full and production Bun audits reported no vulnerabilities
  across 276 and 138 checked packages, and Bun reported no untrusted
  dependency lifecycle scripts.

## Changes

- Updated the approved direct dependency versions in `package.json` and their
  exact resolutions in `bun.lock`.
- Preserved the Codex SDK caret-range manifest style and the existing exact
  pins for Inquirer, Fast XML Parser, and development types.
- Updated the public Codex SDK baseline in `README.md` and
  `docs/guides/cli-action-tool-integration-guide.md` to
  `v0.1.8-canary.2` / `0.151.0`.
- Preserved package version `0.1.8-canary.2`, Node.js engine `>=22.23.0`,
  Node-only compiler ambient types, and the lazy SDK dynamic-import boundary.
- Aligned `@types/node@26.4.0` with the current Node 26 development environment;
  this does not change the Node 22 runtime target of the Tsdown output.

## Validation

- Frozen installation passed with Bun `1.4.0`; 171 installs across 287 packages
  required no changes.
- The updated-lock full and production audits reported no vulnerabilities across
  276 and 138 checked packages respectively, and Bun reported no untrusted
  dependency lifecycle scripts.
- Native `tsc --noEmit` passed with the Node-only ambient-type boundary.
- 81 Codex adapter tests passed across 12 files, 10 OOXML metadata tests passed,
  and the 14 directly checked Inquirer prompt and menu tests passed.
- Oxlint passed without diagnostics, and Oxfmt checked 1,002 files without
  formatting changes.
- The Node 22 build passed with tsdown `0.22.14` and TypeScript `7.0.2`
  declaration generation.
- Under the current Node `26.5.0` development runtime, the CJS and ESM library
  imports, SDK import, built CLI version, and bundled Codex CLI version smokes
  passed. The bundled executable reported `codex-cli 0.151.0`.
- Under the exact declared minimum Node `22.23.0`, the CJS and ESM library
  imports, SDK import, and built CLI version smokes passed; the CLI retained
  package version `0.1.8-canary.2`.
- The full suite passed with 2,623 tests across 355 files and 0 failures.
- `git diff --check` passed.
- Final `bun outdated` showed only `mammoth@1.12.1`, already installed at its
  release-age-qualified candidate and true-latest version.

## Notes

- Canary releases do not receive a manually authored file under `CHANGELOGS/`.
- Tsdown transforms output syntax for Node 22 but does not polyfill Node APIs;
  built-package runtime smokes remain the evidence for the declared engine
  floor.
- The bundled Codex CLI version smoke emitted a restricted-environment warning
  while attempting to create PATH aliases, then reported `codex-cli 0.151.0`
  successfully.
