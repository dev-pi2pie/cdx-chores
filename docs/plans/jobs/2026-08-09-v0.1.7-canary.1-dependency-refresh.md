## Goal

Prepare the existing `v0.1.7-canary.1` package state with the reviewed runtime
and tooling dependency updates, synchronized Codex SDK baseline wording, and
complete validation evidence.

## Scope

- update `@duckdb/node-api` and its matching native bindings to `1.5.5-r.3`
- update `@openai/codex-sdk` and its matching bundled Codex CLI to `0.147.0`
- update `shiki` and `@shikijs/transformers` together to `4.4.2`
- update the exact `oxfmt` and `oxlint` development-tool pins to `0.62.0` and
  `1.77.0`
- preserve the Node.js `>=22.23.0` runtime contract and Node-only ambient types
- keep `@types/node` at `25.9.5` and defer the Node 26 type-baseline move
- update the Codex SDK baseline in `README.md` and
  `docs/guides/cli-action-tool-integration-guide.md`
