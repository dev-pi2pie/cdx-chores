## Goal

Refresh the reviewed low-risk runtime dependency set for the existing
`v0.1.7-canary.3` package state, synchronize the public Codex SDK baseline, and
record focused and repository-wide validation evidence.

## Approved Package Set

- `@openai/codex-sdk`: `0.147.0` -> `0.148.0`
- `@duckdb/node-api`: `1.5.5-r.3` -> `1.5.5-r.4`
- `@shikijs/transformers`: `4.4.2` -> `4.4.3`
- `shiki`: `4.4.2` -> `4.4.3`
- `mammoth`: `1.12.0` -> `1.12.1`
- `papaparse`: `5.5.4` -> `5.6.0`

## Deferred Packages

- Keep `fast-xml-parser` exact-pinned at `5.10.1` until the newer XML parser
  release clears the release-age review and passes focused DOCX/OOXML security
  validation.
- Keep `@types/node` at `25.9.5` because the runtime contract remains Node.js
  `>=22.23.0`; do not adopt the Node 26 ambient type baseline in this pass.
- Keep `oxfmt` at `0.62.0` and `oxlint` at `1.77.0` rather than bypassing the
  minimum-release-age protection for their newest releases.

## Changes

- Updated Codex SDK, its bundled Codex CLI, and platform packages to the
  matching `0.148.0` release.
- Updated DuckDB's Node API, native bindings, and platform packages together to
  `1.5.5-r.4`.
- Kept Shiki core packages and `@shikijs/transformers` aligned at `4.4.3`.
- Updated Mammoth and PapaParse to their reviewed corrective releases.
- Preserved caret ranges for runtime dependencies and left the package version
  at `0.1.7-canary.3`.
- Updated the public Codex SDK baseline in `README.md` and
  `docs/guides/cli-action-tool-integration-guide.md` to
  `v0.1.7-canary.3` / `0.148.0`.

## Package Review

- The published Codex SDK JavaScript and declarations remain unchanged; its
  direct dependency now selects the matching Codex CLI `0.148.0`. The existing
  lazy dynamic import in `src/adapters/codex/shared.ts` remains the compatibility
  boundary.
- The official OpenAI changelog records Codex CLI `0.148.0` as the August 18,
  2026 release and documents its feature, recovery, and sandbox fixes.
- DuckDB `1.5.5-r.4` adds table-function support and corrects cached vectors
  after data-chunk resizing while retaining the existing DuckDB runtime line.
- Shiki and its transformer package remain on one release line, preserving the
  imports used by Markdown PDF highlighting.
- Mammoth `1.12.1` prevents unsafe Windows image output paths and handles
  self-referential numbering styles.
- PapaParse `5.6.0` improves invalid-date serialization and delimiter
  selection. This repository supplies explicit CSV and TSV delimiters, so its
  normal parsing path does not depend on automatic delimiter selection.
