## Scope

Refresh the Codex SDK and Mammoth for the prepared `v0.2.0-canary.2` package without changing its version or Node.js runtime requirement.

## Changes

- Updated `@openai/codex-sdk` from `^0.157.0` to `^0.159.0`; `bun.lock` resolves the matching Codex CLI and six platform packages at `0.159.0`.
- Updated `mammoth` from `^1.12.3` to `^1.13.0`. The lockfile no longer includes its Bluebird and `path-is-absolute` dependencies.
- Updated the current Codex SDK baseline in `README.md` and `docs/guides/cli-action-tool-integration-guide.md` to `v0.2.0-canary.2` / `0.159.0`. The canary.1 job record remains historical.

## Verification

- Frozen installation made no changes. TypeScript check, lint, format check, build, and `git diff --check` passed. The build retained the existing TypeScript 7 experimental-API warning.
- Focused checks passed: 2 live Codex protocol cases / 70 assertions against CLI `0.159.0`, and 9 document-title extraction cases / 42 assertions with Mammoth `1.13.0`.
- `bun run test:all` passed 1,405 unit, 2,147 application, 2 Codex, and 5 Pandoc cases, with no failures, errors, or skips.
- The SDK, built ESM and CJS package, and CLI version smoke checks passed under Node.js `26.5.0`. `bun audit` found no known vulnerabilities across 269 packages, and `bun pm untrusted` found no untrusted dependencies with scripts.

The live Codex checks exercised isolated discovery and protocol behavior; no model-generation request was run. Node.js 22 and 24 were not available for a fresh runtime-floor smoke check in this environment.
