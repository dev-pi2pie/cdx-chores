## Goal

Prepare the existing `v0.1.6-canary.3` package state with a reviewed Codex SDK
runtime update, current formatter/linter/build tooling patches, synchronized
public baseline wording, and complete validation evidence.

## Scope

- update `@openai/codex-sdk` and its matching bundled Codex CLI
- update the exact `oxfmt`, `oxlint`, and `tsdown` development-tool pins
- preserve the Node.js `>=22.23.0` runtime contract and Node-only ambient types
- keep `@types/node@26` outside this refresh
- update the Codex SDK baseline in `README.md` and
  `docs/guides/cli-action-tool-integration-guide.md`

## Changes

- Updated `@openai/codex-sdk` from `0.144.6` to `0.145.0`, including the
  matching bundled Codex CLI and platform packages.
- Updated `oxfmt` from `0.59.0` to `0.60.0`.
- Updated `oxlint` from `1.74.0` to `1.75.0`.
- Updated `tsdown` from `0.22.12` to `0.22.13`.
- Kept `@types/node` at `25.9.5` as an intentional major-version deferral.
- Updated the public Codex SDK baseline to identify
  `v0.1.6-canary.3` / `0.145.0`.

## Package Review

- Confirmed registry signatures, established maintainers, repository identity,
  integrity metadata, and engine requirements for the accepted releases.
- Confirmed that Codex SDK `0.145.0` preserves its import-only ESM export and
  adds cache-write token usage with a compatibility default for older events.
- Preserved the lazy dynamic SDK import in `src/adapters/codex/shared.ts`.
- Reviewed the Oxfmt/Oxlint release changes and retained the existing
  configuration because the updated formatter and linter accept it unchanged.
- Reviewed tsdown `0.22.13`, including its declaration-plugin patch update,
  without changing `tsdown.config.ts`.

## Validation

- `bun install --frozen-lockfile` passed for the Codex SDK checkpoint.
- The SDK import smoke passed and the bundled executable reported
  `codex-cli 0.145.0`.
- Native `tsc --noEmit` passed before and after the tooling update.
- 130 focused Codex adapter and action tests passed.
- `bun run lint` passed with oxlint `1.75.0`.
- `bun run format:check` passed with oxfmt `0.60.0` across 718 files without
  requiring formatting changes.
- `bun run build` passed with tsdown `0.22.13` and TypeScript `7.0.2` declaration
  generation.
- ESM, CJS, CLI, and declaration build artifacts remained byte-for-byte
  identical across the tsdown update.
- The final `bun install --frozen-lockfile` completed without changes.
- The full test suite passed with 1,575 tests across 213 files and 0 failures.
- CJS and ESM library import smokes passed, and the built CLI reported
  `0.1.6-canary.3`.
- `bun audit` reported no vulnerabilities.
- `git diff --check` passed.
- Final `bun outdated` reported only the intentionally deferred
  `@types/node@26.1.1` major update.

## Notes

- Canary releases do not receive a manually authored file under `CHANGELOGS/`.
- The package version was already `0.1.6-canary.3`; this refresh does not
  advance it again.
- TypeScript 7 still emits its expected experimental programmatic-API warning
  during declaration generation; the build succeeds and generated artifacts
  remain unchanged.
