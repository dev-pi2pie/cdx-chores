## Scope

Refresh the four reviewed dependencies for `0.1.9-canary.3` and align the public
Codex SDK baseline with the installed version. The package version and embedded
CLI version were already `0.1.9-canary.3`.

## Updates

| Dependency          | Previous  | Updated   |
| ------------------- | --------- | --------- |
| `@openai/codex-sdk` | `0.155.0` | `0.156.0` |
| `@types/node`       | `26.6.1`  | `26.6.2`  |
| `oxfmt`             | `0.68.0`  | `0.70.0`  |
| `oxlint`            | `1.83.0`  | `1.85.0`  |

The SDK retains the repository's caret-range style in `package.json`; the three
development dependencies remain exact. `bun.lock` resolves the SDK with its
matching Codex CLI, the Oxc platform bindings, and the Node types update. Its 49
changed package entries are limited to those four dependency trees.

## Review

- The published SDK JavaScript and declarations were identical across `0.155.0`,
  `0.155.1`, and `0.156.0`. The SDK's exact Codex CLI dependency moved to
  `0.156.0`, so the isolated protocol suite was the main compatibility check.
- `README.md` and `docs/guides/cli-action-tool-integration-guide.md` now state
  the `v0.1.9-canary.3` / Codex SDK `0.156.0` baseline.
- The new formatter reported no changes across the repository's configured
  formatting scope. The new linter reported no issues.

## Verification

- `bun install --frozen-lockfile` checked 170 installs across 282 packages and
  made no changes. Native `tsc --noEmit`, `bun run lint`,
  `bun run format:check`, and `bun run build` passed. The build still reports
  the TypeScript 7 experimental-API warning.
- The installed Codex CLI reported `0.156.0`, the SDK imported under Node.js,
  and `bun run test:integration:codex` passed 2 cases / 68 assertions.
- `bun run test:all` passed: 1,246 unit cases / 4,798 assertions; 2,038
  application cases / 12,853 assertions; 2 Codex cases / 68 assertions; and
  3 Pandoc cases / 138 assertions. There were no failures, errors, or skipped
  cases.
- The built CLI reported `0.1.9-canary.3`; built ESM and CJS package imports
  passed under Node.js `26.5.0`. This smoke check does not verify the declared
  minimum Node.js version.
- `bun audit` found no known vulnerabilities across 271 packages. `bun outdated`
  reported no candidates, and `git diff --check` passed.
