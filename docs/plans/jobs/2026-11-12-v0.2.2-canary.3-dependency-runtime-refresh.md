## Scope

Refresh reviewed dependencies and tooling for `0.2.2-canary.3`, raise the Node.js compatibility minimum to `>=22.23.5`, and pin both publishing workflows to Node.js `24.22.3`. The existing version-preparation commit is `0ade9355`; the full review starts at its parent, `9ada7c26`. Bun remains `1.4.4`, Node ambient types remain `26.6.6`, and build targets remain `node22`.

The engine range is a compatibility minimum, not a guarantee that every admitted higher Node.js release contains the security fixes. The November security releases are `22.23.5`, `24.22.3`, and `26.13.1`.

## Changes and Checkpoints

| Checkpoint | Changes | Validation |
| --- | --- | --- |
| Node runtime | Manifest, patch-aware test preflight, minimum-runtime smoke scripts, publishing pins, and current runtime documentation | 16 focused preflight/version tests, TypeScript, formatting, actionlint without ShellCheck, and build on Node.js 24.22.3 passed |
| Parser security fixes | parse5 `8.1.1` and PapaParse `5.7.1`; command-local PapaParse release-age exception | Frozen install without lifecycle scripts, TypeScript, 2,090 managed unit cases, audit, and four parser probes passed |
| Runtime dependencies | SDK `0.167.2`, Commander `15.1.0`, Inquirer prompts/search `8.8.0`/`4.4.0`; current SDK baseline docs | Frozen install without lifecycle scripts, 43 command/transport cases, 17 real prompt cases, two managed Codex protocol cases, TypeScript, lint, formatting, and build passed on Node.js 24.22.3 |
| Tooling | Oxfmt `0.78.0`, Oxlint `1.93.0`, tsdown `0.23.7`; Rolldown `1.3.2`, declaration plugin `0.30.1`, Yuku `0.27.0` resolved | TypeScript, lint, formatting, audit, build, unchanged public declarations, and built-package smoke checks on all three patched Node.js lines passed |

The parser checkpoint changes only the two intended artifacts. Their lockfile integrity values match registry metadata, source repositories are unchanged, and neither declares install lifecycle hooks. The probes cover lone surrogate input, deep serialization, formula escaping when explicitly enabled, and large quoted CSV fields. Product CSV export options remain unchanged.

The runtime checkpoint reviews 26 changed artifact versions, including Inquirer helpers, `mute-stream@4`, and the matching Codex CLI/platform packages. Lockfile integrity values match registry metadata; declared engines fit Node.js 22.23.5, and no changed package declares install lifecycle hooks. SDK JavaScript and declarations are unchanged from 0.167.0; installed CLI protocol, search, prompt cancellation, terminal cleanup, and recovery checks pass.

The tooling checkpoint reviews 73 changed artifact versions, including optional platform payloads and the new optional WASI dependency graph. Lockfile integrity values match registry metadata, and no changed package declares install lifecycle hooks. No source reformatting or build configuration changes were needed. The existing TypeScript 7.0 declaration-generator deprecation warning remains; the current generator still builds successfully.

Built-package checks on macOS ARM64 passed with Node.js 22.23.5, 24.22.3, and 26.13.1. Each archive matched official SHA-256 metadata. Checks cover matching ESM/CJS exports, CSV behavior, embedded/CLI version and help, executable mode, both DOCX parsers and six runtime assets, SDK thread construction, Shiki, DuckDB, parse5, and real prompt abort/recovery/search/cleanup. Public declarations are byte-identical to the pre-tooling build. Other native platforms and the optional WASI fallback remain unverified.
