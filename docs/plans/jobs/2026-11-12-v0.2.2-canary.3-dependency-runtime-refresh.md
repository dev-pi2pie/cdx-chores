## Scope

Refresh reviewed dependencies and tooling for `0.2.2-canary.3`, raise the Node.js compatibility minimum to `>=22.23.5`, and pin both publishing workflows to Node.js `24.22.3`. The existing version-preparation commit is `0ade9355`; the full review starts at its parent, `9ada7c26`. Bun remains `1.4.4`, Node ambient types remain `26.6.6`, and build targets remain `node22`.

The engine range is a compatibility minimum, not a guarantee that every admitted higher Node.js release contains the security fixes. The November security releases are `22.23.5`, `24.22.3`, and `26.13.1`.

The broad package minimum is retained deliberately. Inquirer declares `^22.22.2 || ^24.15.0 || >=26.0.0`, excluding Node.js 23, early Node.js 24, and Node.js 25; strict engine checking can reject those versions despite the package minimum. README and testing guidance document this restriction; the testing guide lists the three verified runtimes.

## Prerequisite Test Simplification

The probe calls `isSupportedNodeVersion` in the existing prerequisite module. The helper compares major, minor, then patch against `22.23.5`, accepting higher stable versions. Five unit cases cover the stable-version boundary. The prerelease preservation case was removed; prerelease behavior is outside this check's contract. The application-test file no longer creates a fake executable or depends on a later missing-tool error to prove version acceptance. No runtime, dependency, or CI pins changed.

The full-suite results above describe the dependency-refresh checkpoint before this follow-up. Fresh checks of the final ordered comparison passed: all 2,095 managed unit cases, 11 prerequisite/runner-entry application cases, both managed Codex protocol cases, TypeScript, lint, formatting, and `git diff --check`, using Bun 1.4.4 and Node.js 24.22.3 where required. The full application/Pandoc suites and built-package matrix were not rerun for this test-runner change.

Independent re-review of `9ada7c26..0b85ed1b` found no actionable issues across all 14 changed files before the ordered comparison change. Renewed full-range and documentation reviews remain pending.
