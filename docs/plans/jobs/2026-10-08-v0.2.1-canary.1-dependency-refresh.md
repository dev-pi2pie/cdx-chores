## Review Decisions

- The published SDK diff adds optional `cyberAccessProgram` turn configuration; the existing lazy import and adapter calls remain compatible. The SDK pins its bundled Codex CLI to `0.161.0`.
- The bundled CLI defaults to GPT-6.1 Sol; helpers continue to inherit Codex model/provider configuration when omitted. See the [official Codex changelog](https://learn.chatgpt.com/docs/changelog).
- Inquirer fixes stale async search submission and changes invalid confirmation input to remain in the prompt. See the [Inquirer release notes](https://github.com/SBoudrias/Inquirer.js/releases).
- Keep `oxfmt` at `0.71.0`. Version `0.72.0` changes Markdown formatting, and the repository formatting command includes Markdown fixtures. See the [Oxfmt release notes](https://github.com/oxc-project/oxc/releases/tag/oxfmt_v0.72.0).
- Before the refresh, `bun audit` reported one moderate advisory for `mammoth > argparse > sprintf-js`. The [advisory](https://github.com/advisories/GHSA-hp3w-g68c-fv3c) lists no patched version. This refresh does not remediate it; exploitability in this application's Mammoth API usage has not been established.
