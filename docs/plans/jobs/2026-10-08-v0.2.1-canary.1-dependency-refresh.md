### sprintf-js Advisory Assessment

Before and after the refresh, `bun audit` reported the moderate [GHSA-hp3w-g68c-fv3c advisory](https://github.com/advisories/GHSA-hp3w-g68c-fv3c) through `mammoth@1.13.0 > argparse@1.0.10 > sprintf-js@1.0.3`. The advisory concerns attacker-controlled format strings with unsupported numeric precision, which can cause a `RangeError`. If uncaught, the exception can abort the operation or process.

cdx-chores calls Mammoth's `convertToHtml()` and `extractRawText()` library APIs in [`src/adapters/codex/document-rename/extractors/docx.ts`](../../../src/adapters/codex/document-rename/extractors/docx.ts). Mammoth's library entrypoint (`lib/index.js`) and conversion modules do not import `argparse` or `sprintf-js`; `argparse` is imported by its separate `bin/mammoth` executable. The reviewed product source and built ESM/CJS outputs use the library APIs without invoking that executable.

Static source inspection found no path from DOCX content or cdx-chores arguments to the affected formatter. This specific advisory is therefore assessed as not actionable through the current integration. The installed dependency remains affected, and this refresh does not remediate it. No runtime exploit validation was performed.

Keep the dependency unchanged and retain the audit finding in this record. At the time of the 2026-10-08 review, the advisory listed no patched version. Reassess if Mammoth's dependency structure or the cdx-chores integration changes.
