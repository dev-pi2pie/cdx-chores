## Goal

Apply the reviewed SDK and Bun type patches while preserving package version
`0.1.8-canary.3`, Node.js engine `>=22.23.0`, and tsdown `0.22.14`.
This follows the [completed dependency refresh](2026-09-04-v0.1.8-canary.3-dependency-refresh.md);
its original package versions and validation results remain historical evidence.

## Changes and Review

- Updated `@openai/codex-sdk` from `^0.153.0` to `^0.153.3`, including its
  matching CLI and platform packages in the lockfile. Comparison of the
  published SDK packages found unchanged JavaScript and declarations; only
  the manifest version and matching CLI dependency changed.
- Updated exact `@types/bun` and transitive `bun-types` from `1.4.0` to
  `1.4.1`. The latter includes global event and process listener declarations,
  newer Bun APIs, and version-gated TypeScript 7.1 declarations. Preserved
  TypeScript `7.0.2`, `@types/node` `26.4.1`, and Node-only compiler ambient types.
- Revised README and integration-guide wording to identify the validated SDK
  version, describe existing adapters and template assistance, and clarify
  alternate executable selection and the limits of doctor readiness checks.
- Used one-off release-age overrides for the reviewed packages without changing
  persistent installation policy. Installation used a writable temporary cache.
- Kept the breaking tsdown `0.23.0` migration deferred to separate work.

## Verification

- Focused Codex coverage: 81 tests across 12 files passed.
- Native `tsc --noEmit`, Oxlint, and Oxfmt passed; Oxfmt checked 1,003 files.
- Build passed with tsdown `0.22.14`, Node 22 targets, and declaration generation.
- Frozen installation checked 171 installs across 287 packages without changes.
- Audit found no vulnerabilities across 276 packages; no untrusted dependencies
  with lifecycle scripts were reported.
- Final outdated check lists only intentionally deferred tsdown `0.23.0`.
- Node `24.18.0` and `26.5.0`: ESM, CJS, and SDK imports passed; the built CLI
  reported `0.1.8-canary.3`, and the bundled executable reported
  `codex-cli 0.153.3`. The executable emitted a sandbox PATH-alias warning but
  exited successfully on both versions.
- Validation covers automated tests and local import/executable checks; no live
  authenticated Codex request was made. The exact Node 22 runtime floor was
  not exercised in this follow-up.
- Full suite: 2,632 tests across 356 files passed, with zero failures.
- `git diff --check` passed.
