## Review Decisions

- Keep `engines.node` as the compatibility minimum. Patched Node.js choices for CI remain part of the subsequent security review. Remove the temporary per-major restriction helper, its tests, and the synthetic-repository manifest dependency it introduced.
- Bun 1.4.4 includes package-manager and runtime security fixes and is the development runtime used for this validation. Do not declare a mandatory Bun version in the package manifest.
- DuckDB's revision changes fetch-error propagation, empty-result columns, tuple handling, and result cleanup. DuckDB 2 remains deferred for a separate compatibility review.
- Codex SDK JavaScript and declarations are unchanged; the manifest advances its matching CLI dependency. Preserve the lazy dynamic import and verify installed CLI behavior.
- Direct candidate tarballs matched registry integrity hashes, and their npm registry signatures were cryptographically verified. Repository and publisher metadata showed continuity. Provenance metadata was inspected for six direct candidates; `@types/bun` has no provenance attestation. Provenance signatures and all native platform payloads were not independently verified.
- Rename the maintained manual check to [`video-frames-built-cli-smoke.ts`](../../../scripts/spikes/video-frames-built-cli-smoke.ts). Use purpose-based result and diagnostic wording, update both documentation links, and preserve the existing scratch namespace, ownership checks, budgets, and cleanup behavior.
- README and the CLI integration guide identify the canary's SDK baseline. CI action pins, workflow tool versions, permissions, and publishing architecture were outside this dependency pass. At this checkpoint, both publish workflows selected Node.js 24.18.0. The subsequent [CI action and runtime refresh](2026-10-23-ci-action-pins-and-runtime-refresh.md) updates the action pins and workflow runtimes; broader publishing hardening remains deferred.

Sources: [Node.js October security releases](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases), [Bun 1.4.4](https://bun.com/blog/bun-v1.4.4), [DuckDB Node 1.5.6-r.2](https://github.com/duckdb/duckdb-node-neo/releases/tag/v1.5.6-r.2), [Oxfmt 0.74.0](https://github.com/oxc-project/oxc/releases/tag/oxfmt_v0.74.0), [Oxlint 1.89.0](https://github.com/oxc-project/oxc/releases/tag/oxlint_v1.89.0).
