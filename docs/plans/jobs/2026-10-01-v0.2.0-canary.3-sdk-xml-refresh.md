Update the Codex SDK and XML parser while preserving package version `0.2.0-canary.3` and the Node.js runtime requirement. Synchronize the current SDK baseline in `README.md` and `docs/guides/cli-action-tool-integration-guide.md`; retain historical job records.

The lockfile also updates the matching Codex CLI and six platform packages to `0.159.3`, and `@nodable/entities` to `3.1.0`. No unrelated package entries changed. The SDK retains its caret range; the XML parser remains exactly pinned.

## Review rationale

- Published SDK JavaScript and declarations are unchanged; the package metadata updates its matching Codex CLI dependency. CLI `0.159.3` adds optional account security setup reminders.
- XML `5.11.2` fixes UTF-8 decoding of `Uint8Array` input and changes `EntityDecoderOptions.setXmlVersion` to accept a number. The repository's OOXML adapters pass strings. Its `@nodable/entities` range changes to `^3.0.1`, which resolves to `3.1.0`; that package's runtime JavaScript is unchanged from the previously locked `3.0.0`.
- Downloaded SDK, CLI wrapper, XML parser, and entity package tarballs matched npm integrity hashes. The SDK and XML parser retain GitHub Actions publishing with provenance metadata; attestations were not cryptographically verified, and native CLI binaries were not reviewed.
- Defer `shiki` and `@shikijs/transformers` together at `4.4.3`. Their newly published `4.5.0` release was still inside the configured 24-hour age window at review time and changes highlighting and transformer behavior. Preserve the release-age configuration.

## Verification

- Frozen installation made no changes. Typecheck, lint, format check, build, and `git diff --check` passed. The build retains the existing TypeScript 7 experimental-API warning.
- The SDK import and built ESM/CJS package imports passed under Node.js `26.5.0`; the CLI reports `0.2.0-canary.3`.
- The SDK checkpoint passed 2 isolated live Codex protocol cases / 70 assertions against CLI `0.159.3`. No model-generation request was run.
- All 10 changed lockfile package entries match npm integrity metadata. The updated `bun audit` reports no known vulnerabilities across 269 packages; `bun pm untrusted` reports no untrusted dependencies with scripts.
- `bun outdated` lists only the intentionally deferred Shiki pair.
- `bun run test:all` passed 1,593 unit, 2,269 application, 2 Codex, and 5 Pandoc cases, with no failures, errors, or skips. Result validation, fixture-output validation, and cleanup completed; no results were retained. Application coverage includes OOXML metadata and package-part discovery; unit coverage includes managed test-report parsing.
- Documentation review found no material inconsistencies. Its prose-wrap formatting suggestion was applied, and the final closeout review passed.

Node.js 22 and 24 were not tested in this refresh.
