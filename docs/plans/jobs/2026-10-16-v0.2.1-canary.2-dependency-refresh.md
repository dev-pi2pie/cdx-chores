## Review Decisions

- Published SDK JavaScript and declarations are byte-identical between 0.161.0 and 0.163.0. The package manifest advances its matching Codex CLI dependency. Preserve the lazy dynamic import and verify installed CLI protocol behavior.
- `@types/bun` also advances `bun-types` to 1.4.3. Keep Bun globals outside the main compiler ambient-type configuration.
- Oxfmt 0.72.0 introduced a new Markdown formatter. Reviewed 0.73.0 formatting checks, especially intentional Markdown fixture contents. This revisits the deferral in the [previous maintenance record](2026-10-08-v0.2.1-canary.1-dependency-refresh.md). The 0.73.0 check passes across 1,292 matched files, with an additional explicit check of 16 Markdown fixtures. No formatter rewrites or configuration changes are needed; fixture contents remain unchanged.
- Bun 1.4.3 includes relevant subprocess, test isolation, and installation fixes. Keep the existing TypeScript validation and tsdown build. New Bun runtime APIs are outside this dependency refresh.

Sources: [Bun 1.4.3](https://bun.com/blog/release-notes/bun-v1.4.3), [Oxfmt 0.72.0](https://github.com/oxc-project/oxc/releases/tag/oxfmt_v0.72.0), [Oxfmt 0.73.0](https://github.com/oxc-project/oxc/releases/tag/oxfmt_v0.73.0), [Oxlint 1.88.0](https://github.com/oxc-project/oxc/releases/tag/oxlint_v1.88.0), [tsdown 0.23.1](https://github.com/rolldown/tsdown/releases/tag/v0.23.1).
