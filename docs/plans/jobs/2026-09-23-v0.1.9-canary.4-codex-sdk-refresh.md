## Scope

`0.156.1`. The package and embedded CLI versions were already
`0.1.9-canary.4`. The [canary.3 dependency record](2026-09-23-v0.1.9-canary.3-dependency-refresh.md)

  resolves SDK `0.156.1` with its matching Codex CLI and platform packages.

  [CLI action tool integration guide](../../guides/cli-action-tool-integration-guide.md)
  to `v0.1.9-canary.4` / `0.156.1`.

  declarations, README, and license were unchanged; the manifest changed the
  SDK version and its exact Codex CLI dependency.
