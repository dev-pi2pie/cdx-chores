## Goal

Verify the existing repository under Bun `1.4.0`, align the test-only Bun type
definitions, refresh the reviewed runtime and Oxc dependency set, and advance
the public Codex SDK baseline without changing the Node.js runtime contract.

- [August 19 runtime dependency refresh](2026-08-19-v0.1.7-canary.3-dependency-refresh.md)

  at `>=22.23.0`.

## Package Review

- Bun `1.4.0` is development and test tooling for this repository, not the
  published runtime. Updating `@types/bun` does not justify adding global Bun
  ambient types or adopting Node 26 declarations.
- `@types/bun@1.4.0` resolves through the matching `bun-types@1.4.0`. That
  transitive release was still inside the configured 24-hour minimum age, so
  the reviewed exact package received a one-command age override; persistent
  install policy was not changed.
- Codex SDK `0.149.0` adds raw CLI configuration overrides and the `max` and
  `ultra` reasoning-effort types while retaining the existing API used by this
  repository. The matching Codex CLI is `0.149.0`.
- `fast-xml-parser@5.11.0` changes DOCTYPE handling, malformed closing-tag
  behavior, metadata end indexes, and `strnum`; the exact pin and focused
  DOCX/OOXML validation remain its acceptance boundary.
- `@inquirer/prompts@8.6.0` advances its coordinated prompt dependencies, while
  `@inquirer/search@4.3.0` adds initial-value support and advances Inquirer core.
  They were updated and tested together.
- Oxfmt `0.64.0` adds an optional operator-position feature without changing
  this repository's formatted output. Oxlint `1.79.0` splits React Compiler
  rules and adjusts several diagnostics; this non-React CLI configuration
  produces no new findings.
